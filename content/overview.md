# 行程总览

## 推荐结论

已确认采用 **8月15日深圳直飞大同、8月23日运城直飞深圳** 的北进南出开口线：

> 东莞 → 深圳机场 → 大同 → 悬空寺 → 应县木塔 → 太原 → 平遥 → 王家大院 → 吉县/壶口瀑布 → 运城机场 → 深圳 → 东莞

这条线把山西核心目的地按北向南串起来，不为返程折回太原；全程住宿只设大同、太原、平遥、吉县4个基地，换酒店3次。五台山暂不纳入主线，因为它位于东北方向，会明显增加绕行、换酒店与山路时长，不符合本次“轻松、少回头路”的优先级。
