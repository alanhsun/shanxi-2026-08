# 行程总览

## 一句话方案

采用 **8月15日深圳直飞大同、8月23日运城直飞深圳** 的北进南出开口线：

> 东莞 → 深圳机场 → 大同 → 悬空寺 → 应县木塔 → 太原 → 平遥 → 王家大院 → 吉县/壶口瀑布 → 运城机场 → 深圳 → 东莞

全程9天8晚，只设大同、太原、平遥、吉县4个住宿基地，换酒店3次；不为返程折回太原，也不加入明显绕路的五台山。

山西省内主线改为 **大同云冈机场取车、运城盐湖机场异地还车**。优先预订7座燃油MPV或大空间SUV；古城核心区、晚餐和连续步行日把车留在酒店正规车位，短途打车，不为“全程都开车”增加停车和疲劳风险。

## 体力与节奏

- 每天最晚21:00回酒店；D2、D5、D6保留明确午休。
- 悬空寺以寺下观景为确定项目，只有持线上登临票且全员舒适才登临。
- D3、D7和D9为长途自驾日；每90至120分钟进正规服务区休息，主驾驶不饮酒，任何人困倦就换已登记的第二驾驶人或立即停车。
- 平遥住城外，行李不进古城；城内分上午、傍晚两段慢走。
- 王家大院约2小时即止；D8只安排壶口一个核心项目。

## 租车执行口径

- **车型**：7座燃油MPV优先，其次后备厢能容纳4人行李的大空间SUV；不以纯电动车承担山区长途和D9早班还车。
- **取还车**：8月15日在大同云冈机场网点取车，8月23日在运城盐湖机场网点还车。神州租车公开网点页显示两端均有24小时机场服务点，但指定日期车型库存、异地还车资格和费用必须在订单页再次确认。
- **证件与驾驶人**：取车人携带有效中国大陆身份证和驾驶证；第二驾驶人必须在门店/订单中登记。若没有符合要求的驾驶人，不得临时无证或疲劳驾驶，应立即恢复原高铁＋正规包车备选。
- **费用核对**：下单前把租金、基础/补充保障、手续费、异地还车费、儿童增高坐垫、燃油、路桥和停车全部换算为人民币总价比较；当前预算只是规划区间。
- **验车还车**：取车时环车连续录像，拍轮胎、玻璃、油表/电量、里程和已有划痕；D9在机场附近补足约定油量，保存加油票并拍还车照片。

## 现场统一规则

- 云冈入园后先完成第5、6窟等核心区域，局部开放顺序以现场为准。
- 山西博物院只看重点展，讲解使用官方预约或馆内语音；晋祠先到核心区。
- 双林寺千佛殿处于分段半封闭保护施工，其他殿宇仍参观，不保证近距离看到殿内重点彩塑。
- 平遥拒绝未经邀请的导游、三轮和体验推销；任何消费先问清4人总价、包含项和成品能否带走。
- 餐厅等位20至30分钟即换同区域备选；整桌尽量不辣，先少点再加菜。
- 壶口汛期视角和开放范围可能变化，闭园就回吉县休息，不临时跨河绕行陕西侧。
- 所有驾驶日严禁酒驾、疲劳驾驶和抢时间；山区暴雨、能见度差或临时管制时，以停车等待或取消景点为优先。
