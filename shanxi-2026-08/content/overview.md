# 行程总览

## 一句话方案

采用 **8月15日广州经宁波飞大同、8月23日运城直飞广州** 的已出票北进南出开口线：

**路线：** 东莞 → 广州 → 宁波 → 大同 → 悬空寺 → 应县木塔 → 雁门关/代县 → 五台山 → 太原 → 平遥 → 王家大院 → 吉县/壶口瀑布 → 运城 → 广州 → 东莞

山西省内全程租车自驾，路线保持一路向南，不为返程折回太原。为加入雁门关和五台山，太原、平遥各缩为1晚并删除晋祠；为衔接07:20返程，D8改住运城机场对面。总计7个住宿基地、6次换酒店。

### 五台山价格阈值

8月5日同日同人数快照：妙隐居核心区328元；美丽豪南门外地下三人间294元、地上双床房324元。由于价差仅34元，主选核心区。只有同时满足 **总价≤450元、明确接待3人、可免费取消** 才保留；任何一项不满足就切南门外，并接受免费公交换乘。价格仍未锁定，下单时以结算页为准。

8晚住宿规划合计约 **2,700–4,450元**；其中运城微源国际酒店已订大床房178元。总额其余部分仍保留动态房价缓冲，不能视作已付总房费。
