# 行程总览

## 一句话方案

采用 **8月15日广州经停武汉飞大同、8月23日运城直飞深圳** 的北进南出开口线：

**路线：** 东莞 → 广州 → 大同 → 悬空寺 → 应县木塔 → 雁门关/代县 → 五台山 → 太原 → 平遥 → 王家大院 → 吉县/壶口瀑布 → 运城 → 深圳 → 东莞

山西省内全程租车自驾，路线保持一路向南，不为返程折回太原。为加入雁门关和五台山，太原、平遥各缩为1晚并删除晋祠；总计6个住宿基地、5次换酒店。

### 五台山价格阈值

8月5日同日同人数快照：妙隐居核心区328元；美丽豪南门外地下三人间294元、地上双床房324元。由于价差仅34元，主选核心区。只有同时满足 **总价≤450元、明确接待3人、可免费取消** 才保留；任何一项不满足就切南门外，并接受免费公交换乘。价格仍未锁定，下单时以结算页为准。

8晚住宿规划合计约 **2,900–4,700元**。

## 体力与自驾边界

- D3景点多：悬空寺寺下观景为保底，雁门关只走北门核心区；15:30仍未到雁门关则取消。
- 五台山不做五台连穿、不爬黛螺顶1080级台阶；车辆未预约成功就停指定停车场换免费公交。
- D6平遥只做夜景，D7清晨完成城墙短段＋县衙/日升昌二选一；不再安排完整一天。
- 每90–120分钟进正规地点休息；第二驾驶人须登记，8岁儿童使用适龄增高坐垫。
- 每晚21:00前回酒店；山区暴雨、落石预警、能见度差或临时管制时，取消景点而不是赶路。
