## 一句话方案

采用 **8月15日广州经宁波飞大同、8月23日运城直飞广州** 的已出票北进南出开口线：

**路线：** 东莞 → 广州 → 宁波 → 大同 → 悬空寺 → 应县木塔 → 雁门关/代县 → 五台山 → 太原 → 平遥 → 王家大院 → 吉县/壶口瀑布 → 运城 → 广州 → 东莞
